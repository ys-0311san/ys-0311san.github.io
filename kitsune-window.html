狐の窓

指の窓越しにだけ、もうひとつの姿が見えるアバターギミック

近日公開アバター用

公開したら BOOTH と X でお知らせします。

指を組んで小さな窓をこしらえ、その隙間から覗くと、化けているものの正体が見える――。「狐の窓」と呼ばれる、古くからの言い伝えです。

このギミックは、その窓をあなたのアバターに宿します。両手のピースの指先を合わせて菱形の窓（輪っかも）をつくると、その窓越しに覗いたところだけ、あなたの姿が、もうひとつの姿に変わります。窓の外は、いつもの姿のままです。

機能

指の窓

両手のピースの指先を合わせた菱形（輪っかも）を窓と見分け、窓越しに見えたところだけが窓の中の姿で描かれます。

狐の窓枠

ゲーム内メニューから、手のひらの上に狐の形の窓枠を出せます。大きさは手の大きさに合わせます。

狐の窓 ON

窓越しに見たところだけ、窓の中の姿になります。着たときやワールドに入ったときは、いつも OFF から始まります。

窓の中のみ

窓をつくらなくても、全身が窓の中の姿になります（鏡の中も）。

自分だけの姿

自分の画面でだけ、全身が窓の中の姿になります。まわりの人には、いつもの姿のまま見えます。

写真にも写る

VRChat のカメラで撮った写真に、それぞれの見え方のとおり写ります。

入れ方と取り外し

日本語のセットアップ画面で5つの手順を選ぶだけ。元のアバターには手を加えず、コピーに入れます。取り外しもセットアップ画面からできます。

オプション（変身・鬼火）

アバター用のオプションです。窓の中に別のアバターを出す「変身」と「鬼火」があります。本体と一緒に入れて使います。

使い方

  1. 本体の unitypackage を Unity のプロジェクトに取り込みます（オプションもお持ちなら続けて取り込みます）
  2. 「Tools」→「狐の窓」→「セットアップ…」を開き、5つの手順を順に選んで［セットアップ］を押し、アバターをアップロードします
  3. VRChat で、アクションメニュー →「狐の窓」→「狐の窓 ON」を ON にして、指で窓をつくって覗きます

必要な物

  • Unity と VRChat SDK（Avatars）
  • Modular Avatar と、一緒に入る NDMF
  • lilToon（狐の窓枠などに使います）
  • 窓で切り替わる素材は、lilToon と Poiyomi です。それ以外の素材は、lilToon に変換した複製を作って切り替えます（見た目が元と変わることがあります）
  • PC 専用です（Android / Quest 向けのビルドでは窓が動きません）
  • 画面・説明書・サポートは日本語のみです
  • VRChat SDK・Modular Avatar・NDMF・lilToon などは同梱していません。それぞれの配布元から入手してください

気をつける事

  • 鏡の中では、窓は効きません（「窓の中のみ」のときは、鏡の中も窓の中の姿になります）
  • 目から 50cm より遠い輪は窓になりません（腕を伸ばしきると反応しません）
  • 影のつくライトが無いワールドでも窓が開くよう、深度用のライトを 1 つ入れます。そのため PC のパフォーマンスランクは Poor 以下になります
  • 変身は、重さ・ダウンロードサイズ・パフォーマンスランクが、アバター約 2 体分になります
  • 見る人の安全設定でシェーダーが止められていると、その人にはいつもの姿のまま見えます

ワールド用: 狐の泡 準備中

ワールドに置く、被ると窓の中の姿が見える泡

泡を頭に被ると、その人の画面でだけ、ほかの人の窓の中の姿が見えます（指で窓を作らなくても見えます）。ワールドを作る方向けで、ワールド用のプロジェクトに入れます。

今は販売していません。準備ができたら BOOTH と X でお知らせします。

ワールド作り向け

ワールド用の Unity プロジェクト（VRChat SDK（Worlds））に入れる別のパッケージです。アバター用のプロジェクトには入れません

いくつでも置ける

自分にも、ほかの人にも被せられます

見える条件

窓の中の姿が見えるのは、相手がアバターに狐の窓を入れていて「狐の窓 ON」か「窓の中のみ」を ON にしている時です

外し方

ジャンプボタンを 3 秒押し続けるか、泡の前のリセットボタンを押すと外れます

必要な物

  • Unity と VRChat SDK（Worlds）。U#（UdonSharp）は SDK に入っているので別に入れなくてよい
  • 本体（アバター用）のパッケージは要りません

ペッター

自分のアバターがペットになって付いてくる追従ギミック

販売中アバター用

BOOTH で見る

あなたのアバターが、もう1体。自分の足で歩いて付いてきます。

いつも使っているアバターを、そのままペットにできます。あなたが歩けば歩き、離れれば駆け足になり、立ち止まればそばで待つ。浮かんでいるのではなく、脚を動かして付いてくるペットです。

機能

自分の足で歩く

歩き・ダッシュ・待機のモーションが自動で切り替わり、後ろを追従します。

どの Humanoid でも

モーションをペットのリグへ焼き込むので、Humanoid のモデルならどれでも脚が動きます。

今の見た目のまま

Hierarchy のアバターでもプレハブでもペットにできます。着せ替えた今の見た目のままペットになります。

大きさ 30cm〜2m

追従の距離は、大きさに合わせて自動で調整されます。

お座りで留まる

「お座り」でその場に留まります。向きも固定されます。

お座り位置の同期

お座りで止めた場所と向きを、ほかの人の画面ともそろえられます（オプション）。後から Join した人にも、止めた場所に見えます。

高さと表示の調整

メニューから高さ調整（上下 25cm）と、表示 / 非表示ができます。

取り外して戻せる

「ペッターを取り外す」で、セットアップ前へ戻せます。ホバーモード（浮遊）と板状（平面）のモデルにも対応します。

使い方

  1. unitypackage を、VRChat SDK3 - Avatars と Modular Avatar を入れた VCC のプロジェクトにインポートします
  2. 「Tools > ペッター > セットアップ」を開き、アバターとペットモデルを指定して「全部セットアップ」を押します
  3. VRChat 内では、アクションメニューに「ペッター」というサブメニューが追加されます

必要な物

  • Unity と VRChat SDK3 - Avatars
  • Modular Avatar
  • ペットにするモデルは Humanoid リグが必要です（Generic の場合は、どこを変えればよいかが画面に表示されます）
  • 位置の同期に使う VRLabs Custom Object Sync は同梱しています（VCC での追加は不要です）
  • PC（Windows）専用です。Quest / Android には対応していません
  • くわしくは BOOTH の商品ページをご覧ください。

気をつける事

  • ホバーと身長はセットアップ時に焼き込まれます。変えるにはやり直してください
  • VRChat でアバターの大きさを変えると、追従の距離がずれます
  • 歩いて付いてくる間のペットの位置は同期していません。見ている人それぞれの画面で計算しているため、少しずれることがあります
  • 購入したアバターをペットにする場合は、そのアバターの利用規約に従ってください
